Connect Notion

1. Go to notion.so/my-integrations and create a new Integration, then copy the "Internal Integration Secret".
2. In Notion, create a Database, then use the "⋯" menu → "Connections" to add the integration you just created.
3. Copy the database URL and paste it below (or paste the database ID directly).

The database's property types (not names) decide where each piece of data goes: a "Title" property stores the text, a "URL" property stores the source link, a "Select" property stores the topic, "Text" properties store the thought and page title, and a "Date" property stores the time.
