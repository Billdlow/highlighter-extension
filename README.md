# 劃重點筆記(v1.0)

選取網頁上的文字,自動跳出小工具列,一鍵劃重點並記錄來源網址、頁面標題與時間。所有劃記都存在瀏覽器本機,可在擴充套件視窗裡搜尋、加備註、複製或刪除。

## 目前功能

- 選取文字 → 跳出浮動工具列 → 選一個顏色劃記(黃/綠/粉/藍)
- 劃記後**立刻**跳出小視窗,可以寫下你自己的想法、選一個主題分類(或新增主題)
- 每筆劃記自動記錄:原文、來源網址、頁面標題、時間
- 點擊已劃記的文字 → 可以編輯想法/主題,或刪除這筆標記
- 點工具列上的 🔗 → 複製「文字 + 來源連結」,方便貼到別處
- 擴充套件圖示 → 打開清單,可依主題篩選、搜尋、複製、刪除
- **連接 Notion**:設定好之後,每次儲存想法會自動同步到你指定的 Notion 資料庫
  - **有選主題**:同一個主題的所有劃記,會合併寫進 Notion 裡「同一個頁面」,每筆劃記變成該頁面裡的一段內容(原文用引用格式、你的想法用一般段落、來源連結附在下面),方便同主題的重點集中閱讀。表格上的 Name/Thought/Date 欄位也會自動更新:Name 顯示「共 N 篇來源・詳見下方內文」,Thought 顯示最新一筆想法,Date 顯示最後更新時間;URL 欄位刻意留空(因為一個主題頁面裡混合多個不同來源網址,放單一網址會誤導),Name 欄位裡的說明文字就是在講這件事
  - **沒選主題**:每筆劃記還是一行資料,但**標題只放前 20 字精簡摘要**,完整原文/想法/來源連結會寫進該筆資料的頁面內文裡(點開那一行就能看到完整內容),避免表格欄位被塞爆。Name/Thought/Category 也不留白:Name 顯示「詳見下方內文」、Thought 顯示你的想法(沒寫就顯示「未寫想法」)、Category 顯示「不分類」
- **AI 知識圖譜**(目前已隱藏,見下方說明):把劃記重點自動整理成「前置知識 / 核心概念 / 實際用例 / 延伸領域」四類架構(需要設定 AI API 金鑰)
- **截圖附件(選用,非自動)**:想法視窗裡有「📷」跟「🖊」兩個獨立圖示按鈕(滑鼠移上去會顯示英文提示 Screenshot / Annotate screenshot),不點就完全沒有截圖。點下去會先截取完整畫面,再跳出**可自己拖曳框選範圍**的畫面(跟電腦內建截圖工具一樣,想連旁邊的圖片一起框進去就直接拖曳擴大範圍,介面文字為英文),確認範圍後如果是「🖊 標注」才會接著跳出編輯畫面,可以用螢光筆拖曳塗劃、或點「📝」放便利貼寫文字。只有真的附上截圖的那幾筆,同步時才會把圖片一起傳到 Notion
- **AI 朗讀**:劃記想法視窗跟清單頁都有 🔊 按鈕,點下去用瀏覽器內建語音唸出原文,完全本機處理、不用設定任何金鑰、不花錢。朗讀前會自動清掉像「[13][14]」這種來源網站常見的註腳編號跟多餘空白,聽起來比較不雜。可以到設定頁挑選比較自然的語音(取決於你電腦上安裝了哪些語音包)、調整朗讀速度(預設 0.9x,比正常再慢一點),並試聽效果

## 知識圖譜功能目前隱藏中

因為送審 Chrome 商店時,被判定 Notion 以外的 API 網站權限(Anthropic、OpenAI)沒有對應的可觸發功能,所以 v1.0.1 版本把彈出視窗裡的「Knowledge Graph」入口按鈕、設定頁的 AI 金鑰設定區塊都先隱藏,連帶把這兩個網域的權限從 manifest.json 移除。程式碼(background.js 裡的 generateKnowledgeGraph 等函式、graph.html 頁面)都還在,只是沒有入口可以觸發,之後想重新開放,把 popup.html/popup.js/options.html/options.js 裡對應被註解掉的區塊還原、並把權限加回 manifest.json 即可。

## 怎麼用知識圖譜功能(功能重新開放後適用)

1. 到設定頁(⚙)填上 AI API 金鑰(Anthropic Claude 或 OpenAI 擇一,用你自己的金鑰,費用由你自己的帳號負擔)
2. 打開擴充套件圖示,點「知識圖譜」按鈕,會開一個新分頁
3. 可以先選一個主題篩選(建議),或直接用全部劃記(最新 60 筆),按「產生知識圖譜」
4. AI 會分析這批重點,分成四欄呈現,每筆都附上一句分類理由跟可以點回去的來源連結
5. 結果會存起來,下次打開不用重新產生;想更新就再按一次「產生知識圖譜」(會重新呼叫 AI,產生一次消耗一次 API 額度)

## 怎麼設定 Notion 同步

1. 點擴充套件圖示右上角的 ⚙,或直接在 `chrome://extensions` 找到這個擴充套件按「詳細資料」→「擴充功能選項」
2. 前往 [notion.so/my-integrations](https://www.notion.so/my-integrations) 建立一個新的整合(Integration),複製「Internal Integration Secret」貼到設定頁
3. 到 Notion 建立(或選一個現有)資料庫,右上角「⋯」→「Connections」把剛剛建立的整合加進去,這一步不做,同步會失敗
4. 把資料庫網址複製貼到設定頁的「資料庫網址或 ID」欄位,會自動抓出正確的 ID
5. 資料庫裡的**欄位型別**決定同步內容會放到哪裡(欄位名稱可以自己取):
   - 一個「標題(Title)」欄位 → 放劃記的原文
   - 一個「URL」欄位 → 放來源連結
   - 一個「選項(Select)」欄位 → 放你選的主題(沒有的選項會自動建立)
   - 「文字(Text)」欄位 → 放你的想法跟頁面標題(建議準備兩個文字欄位)
   - 一個「日期(Date)」欄位 → 放劃記時間

## 目前限制(下一版再處理)

- 重新整理頁面後,畫面上的螢光筆標記不會自動恢復(但資料本身還在,清單裡看得到、連結也點得回去)
- 還沒有 AI 自動摘要功能
- Notion 同步用的是「內部整合金鑰」,不是帳號登入,所以只能同步到你自己設定過權限的資料庫
- 截圖只能截到「目前螢幕看得到的範圍」,不是整頁長圖;如果劃記的段落剛好在螢幕外(要捲動才看得到),那筆就不會有截圖
- 截圖上傳到 Notion 需要多打幾次 API,如果那次 Notion 服務比較慢,同步時間會比純文字久一點點

## 怎麼安裝(開發者模式,上架前先自己測試用)

1. 打開 Chrome,網址列輸入 `chrome://extensions`
2. 右上角打開「開發人員模式」
3. 點「載入未封裝項目」
4. 選擇這個資料夾(`highlighter-extension`)
5. 完成,現在去任何網頁選取文字試試看

## 檔案說明

- `manifest.json` — 擴充套件設定檔
- `content.js` / `content.css` — 注入網頁的劃記工具列與標記樣式
- `popup.html` / `popup.js` / `popup.css` — 點擊擴充套件圖示後看到的清單視窗
- `icons/` — 擴充套件圖示
